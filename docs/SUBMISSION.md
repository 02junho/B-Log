## AI 활용 방식 및 결과 (500자 제한 — 현재 441자, 최종 문구 9/17)

```
세션 로그를 분석하는 제품이면서, 그 과정 자체를 AI와 함께 만든 프로젝트입니다. ① 제품 내부: Upstage Solar Pro 4가 Claude Code·OpenAI Codex 세션 로그를 '문제 정의→AI 지시→근거 탐색→실패·복구' 4단계로 정리합니다. 원문에 실제로 있는 인용만 자동 검증해 싣고, 커밋과 대화를 작성자·시간 기준으로 연결하며, 정규식과 LLM의 이중 마스킹과 발행 전 검수를 거칩니다. ② 개발 과정: 구현은 Claude Code와 Codex가 맡고, 아키텍처 결정과 프롬프트 설계, 코드 리뷰와 검증은 사람이 판단했습니다. ③ 결과: 10일간의 개발 로그(이벤트 959개)를 서비스 스스로 분석해, 검증된 순간 170개와 커밋 29개가 연결된 '메타 포트폴리오'로 공개했습니다. 태깅 JSON 유효율 100%, 세션당 분석 비용은 약 $0.1로 측정했습니다.
```

말투 정리 내역(9/17): "제품이자"→"제품이면서", "태깅하고~만듭니다" 한 문장 분리, "기계 검증"→"자동 검증", "지휘했습니다"→"판단했습니다", "서비스 자신이"→"서비스 스스로", 조사·연결어 자연화.
